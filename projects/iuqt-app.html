IUQT Modular Ecosystem

A massive, multi-module Flutter platform designed for real-time social interaction and commercial exhibition.

The Challenge

Building a super-app that combines features of WeChat, TikTok, and E-commerce requires a highly scalable and modular architecture to prevent technical debt and ensure fluid user experience.

Architecture & Modules

Developed using MVVM with GetX & Provider for robust state management. The app is divided into high-impact modules:

Chat Module

Real-time messaging, audio/video calls using WebRTC and LiveKit SDK. Supported by local SQL storage for offline access.

Media Module

TikTok-style vertical video feed with custom streaming optimizations, real-time likes, and threaded comments.

E-commerce

A fully integrated storefront with real-time inventory and secure checkout flows.
