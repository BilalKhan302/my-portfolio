Automated AI Attendance

A secure, automated attendance system leveraging Hybrid Vision Transformers and ResNet with integrated anti-spoofing.

Project Overview

Traditional facial recognition attendance systems are vulnerable to presentation attacks (photos, deepfakes). This project focuses on building a "Liveness" verified system that ensures physical presence.

Technical Methodology

The core engine uses a Hybrid Transformer-ResNet architecture. ResNet handles local feature extraction for face geometry, while the Vision Transformer (ViT) captures global dependencies and subtle liveness cues (e.g., micro-movements, texture analysis).

Security Components

  • Anti-Spoofing: DeepFake detection using temporal analysis.
  • ResNet-50: Robust facial feature embedding.
  • Real-time Inference: Optimized for edge deployment.
