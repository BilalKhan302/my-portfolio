DeenIslam App

A modern, minimalist Islamic mobile applications focusing on spiritual guidance, real-time data accuracy, and exceptional user experience using Flutter.

Role

Lead Developer & UI Designer

Tech Stack

Flutter, Firebase, Cloud Functions, REST

Platform

iOS & Android

Problem Statement

Many Islamic apps are cluttered with intrusive ads and outdated UI/UX patterns. Users often struggle with inaccurate prayer timings due to poor location algorithms or inconsistent data sync across devices. There was a clear need for a "premium" alternative that respects the user's focus and provides precise religious data.

The Approach

We prioritized a "User-First" design philosophy, utilizing Apple's Human Interface Guidelines for the iOS experience while maintaining a consistent Material Design 3 feel on Android. We built a robust backend on Firebase to handle real-time prayer time calculations and Quranic audio streaming with low latency.

Core Features

Precision Timings

Advanced astronomical algorithms that calculate prayer timings with high precision based on GPS coordinates, supporting multiple calculation methods globally.

Immersive Quran

A beautiful reading experience with customizable typography, multiple translations, and high-quality recitations available for offline listening.

Qibla Finder

Real-time AR-based Qibla compass that provides an interactive way to find direction accurately anywhere in the world.

Tech Stack Details

Built with efficiency and scalability in mind.
