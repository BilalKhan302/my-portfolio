Cashier Management System

A high-performance store management and POS system for Chinese retail chains, integrated with real-time digital payments.

The Solution

Developed to streamline store operations for high-traffic Chinese retail stores. This ERP-lite mobile application manages everything from inventory restocking to multi-channel customer service.

Key Capabilities

  • Payment Integration

    Native integration with Alipay and WeChat Pay using QR code scanning for lightning-fast checkout.

  • Real-time Sync

    Utilizes Sockets and WebRTC for real-time stock updates and synchronized data across multiple cashiers.

  • Architecture

    Built using MVVM with Provider + GetX for efficient state management and clean code separation.

  • Local Storage

    Embedded SQL database ensures zero data loss even during network interruptions.
